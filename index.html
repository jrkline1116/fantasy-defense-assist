How to use it for streaming defenses

Each week, look down the next week's column for green cells. Green means the defense is facing an offense that opposing D/STs have scored well against this season, so it's a strong streaming pickup. Red means opposing defenses have struggled against that offense, so it's one to avoid. Click the week's header to sort the best matchups to the top, mark the teams already rostered in your league, and flip Hide taken to see only the defenses you can actually claim.

To stash a defense, look further ahead. A team with a run of green cells two or three weeks out, or a strong matchup during the fantasy playoffs, is worth picking up before the rest of your league notices. Byes are marked so you can plan around them.

How the rankings are calculated

For every game played this season, we score the defense that faced each offense using standard fantasy D/ST rules: sacks, interceptions, fumble recoveries, defensive and return touchdowns, safeties, and points allowed. Each offense's average is ranked from 1st (defenses score the fewest points against it) to 32nd (defenses score the most). Click any matchup to see the game-by-game breakdown behind the number.

The tabs switch between each platform's default scoring. ESPN also scores yards allowed and uses smaller points-allowed bonuses. Yahoo and Sleeper use the same defaults as each other: bigger bonuses for holding an offense to a low score and no yards-allowed scoring. That's why an offense can rank differently from one tab to the next.

Data comes from public NFL box scores and updates every Tuesday morning after Monday Night Football. Ranks can differ slightly from each site's own numbers because blocked kicks and 2-point returns aren't included.
